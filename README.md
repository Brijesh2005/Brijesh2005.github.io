# Brijesh Vishwakarma - Professional Portfolio

Modern portfolio website for Brijesh Vishwakarma (Full Stack Developer & AI/ML Engineer).

## Features
- Light-to-moderate editorial tech design with dynamic theme palette switcher (Indigo, Emerald, Cyan, Amber).
- Interactive Canvas Constellation background responding to mouse dynamics.
- Shipped GitHub Projects showcase with dual Preview/Code views and live interactive simulation modals (Sentinel Watch, CropFusion, Fire & Smoke Detection, WaterMan).
- Interactive Developer Terminal CLI.
- Quick Resume (CV) modal with instant print/PDF support.

## Tech Stack
- HTML5 & CSS3 (Custom Properties, Glassmorphism, Responsive Grid/Flexbox)
- Vanilla JavaScript (ES6+, Web Audio API, Canvas API, IntersectionObserver)
